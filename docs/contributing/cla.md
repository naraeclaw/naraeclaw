# Contributor License Terms

NaraeClaw accepts contributions under the same dual-license model used by the
repository: **MIT OR Apache-2.0**.

This document replaces the upstream ZeroClaw Labs CLA text for this fork. It is
not a separate signature process and does not transfer ownership of your work.

## Contribution License

By submitting a contribution to NaraeClaw, you agree that your contribution is
licensed under both of the following licenses, at the recipient's choice:

- MIT License — see `LICENSE-MIT`
- Apache License 2.0 — see `LICENSE-APACHE`

This keeps inbound and outbound licensing aligned: code accepted into the
repository can be used under the same license terms as the rest of the project.

## Rights You Keep

You retain copyright ownership of your contribution. You remain free to use your
own work elsewhere under any license you choose, as long as you have the right to
do so.

## Original Work and Third-Party Code

Only submit work that you have the right to contribute. If a contribution
includes third-party code, generated assets, copied examples, or externally
licensed material, disclose the source and license clearly in the pull request or
commit message.

Do not submit code, data, examples, or documentation that contains secrets,
personal data, customer data, or material you are not allowed to publish.

## Patent License

When you submit a contribution under Apache License 2.0, you provide the patent
license described in that license for patent claims necessarily infringed by your
contribution.

## Fork Attribution

NaraeClaw is a fork of ZeroClaw. Upstream attribution is preserved in `NOTICE`,
`LICENSE-MIT`, and repository history. New NaraeClaw contributions are attributed
through commit history and release metadata.

## Questions

Open an issue in the NaraeClaw repository if a contribution has unusual license
or attribution requirements before merging it.
