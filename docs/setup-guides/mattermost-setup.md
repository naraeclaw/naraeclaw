# Mattermost Integration (Unsupported)

**Status:** Removed from the current public channel configuration.

The active `ChannelsConfig` supports CLI and Slack only. Older Mattermost token, team,
channel, polling, and allowlist settings are not part of the current config contract.
Do not use this page as a deployment guide.

This stub remains so old links fail safely instead of presenting stale credentials and
commands as supported behavior. Reintroducing Mattermost requires a scoped channel change,
public schema, allowlist and failure-mode tests, and updated security/operations docs.

See [Channels Reference](../reference/api/channels-reference.md) for supported surfaces.
